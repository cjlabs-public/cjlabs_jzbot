# cjlabs_记账机器人

cjlabs_记账机器人是一个 Telegram 机器人，用于在 Telegram 私聊或群组中辅助记录与管理信息，并提供常用的群组机器人能力。

## 机器人功能

- 私聊欢迎与引导：发送 `/start` 后，机器人会返回欢迎信息和快捷操作按钮。
- 命令帮助：发送 `/help` 可以查看当前可用命令列表。
- 查询自己的 Telegram 用户 ID：在私聊中点击「我的ID」按钮，机器人会返回昵称、用户 ID 和用户名。
- 群组接入提醒：将机器人加入群组后，机器人会发送群组欢迎信息，并提示可用命令。
- 用户、机器人、群组或频道信息识别：支持处理 Telegram 的用户分享和群组/频道分享消息，返回对应 ID、用户名、群组名称等信息。
- 群组能力预留：代码中已预留群组设置、入群验证、签到、抽奖、活动组织等扩展能力。

## 如何使用

1. 打开 Telegram，搜索并使用 `@cjlabs_jzbot`。
2. 或直接打开机器人链接：<https://t.me/cjlabs_jz_bot>
3. 在私聊中发送 `/start` 开始使用。
4. 发送 `/help` 查看当前支持的命令。
5. 如需在群组中使用，请将机器人添加到目标群组，然后在群内发送 `/start` 或 `/help`。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `/start` | 开始使用机器人，查看欢迎信息和快捷按钮 |
| `/help` | 查看当前可用命令列表 |
